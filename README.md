# Leadout Capital

Leadout Capital is an early-stage venture capital fund in Portola Valley, California, founded in 2018 by
Ali Rosenthal. The firm leads, co-leads, or takes a significant position in pre-seed and seed rounds, with a
thesis built around **founder-market fit** — founders whose unique market insight is born of their own lived
experience. Leadout is a partner fund within Foundry Group's network-driven limited-partner model.

- Website: https://www.leadoutcapital.com
- Portfolio: https://www.leadoutcapital.com/portfolio
- Team: https://www.leadoutcapital.com/team
- Blog: https://leadoutcapital.medium.com/

## Note on API artifacts

Leadout Capital publishes **no public API** — no OpenAPI, SDK, MCP server, sandbox, or developer portal.
API-dependent artifact types (`openapi/`, `packages/`, `mcp/`, `authentication/`, `errors/`, `conventions/`,
`skills/`, and the rest) are intentionally absent rather than fabricated.
